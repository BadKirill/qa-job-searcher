# Восстановление доставленных вакансий

`qa_job_bot.history_import` читает локальную историю `deliveries` начиная с указанной
даты, восстанавливает публичные описания и применяет текущий `SearchProfile` через
`match_job` и `rank_jobs`. В основную выдачу допускается только география `allowed`.
Telegram API не используется: для Telegram нужен уже сохранённый текст.

По умолчанию команда только пишет приватный отчёт:

```sh
PYTHONPATH=src .venv/bin/python -m qa_job_bot.history_import
```

`--apply` сохраняет проверенные данные и объединяет их идентификаторы с настройкой
`imported_jobs`. Настройка `current_jobs`, история доставок и пользовательские
applied/archive остаются прежними. Для совпадения `source`/`source_id` используется
идентификатор текущей выдачи; исторические строки сохраняются. Нормализация названия,
компании и географии не меняет сохранённый идентификатор вакансии.

`--resume data/history-import-report.json` использует успешные результаты прошлого
отчёта при неизменном профиле и проверяет только недоступные записи. До времени
`next_retry_at` повтор запрещён. HTTP 429 останавливает дальнейшие запросы к этому
источнику в текущем запуске; уже начатых запросов может быть не более четырёх.
`Retry-After` поддерживается в секундах и в формате HTTP-date; если заголовка нет или
он некорректен, устанавливается пауза 30 минут. Автоматических циклов повторов нет.

Сеть ограничена HTTPS, точными именами публичных источников и разрешёнными путями.
DNS должен вернуть только публичные адреса; соединение закрепляется за проверенным
IP с исходными Host и TLS SNI. Перенаправления запрещены, ответ ограничен 2 MB.
Из Hirify берётся видимое публичное описание и метаданные соответствующего ID;
скрытый исходный текст и платный доступ не используются.

Отчёт содержит все исходные записи, причины фильтрации, дубли, метод восстановления,
ошибки получения, отпечаток текста и количество новых/уже текущих результатов.
`public_page_available` означает доступность страницы, а не гарантию открытого найма.
Недоступность источника не означает закрытие. Явная архивность или отметка scam
отклоняет вакансию даже при наличии старого текста. Старый сохранённый текст при
сетевой ошибке отмечается `stored_payload_fallback` и `availability=unknown`.

Отчёты и SQLite хранятся в игнорируемом `data/`; их нельзя коммитить. Перед реальным
импортом следует сделать согласованную приватную SQLite backup-копию.
