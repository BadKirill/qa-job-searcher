# Исходники двух версий

22 ноября 2026 актуальный многопользовательский release добавлен в Git в каталог
`multiuser/`. До этого его исходники находились только в игнорируемом `.runtime`.
Каталог содержит backend, миграции, frontend, тесты, зависимости, Compose,
Dockerfile и документацию. Он включает новую палитру и проверку геометрии интерфейса.
Из 120 файлов приложения в манифесте проверки отступов 119 совпадают побайтно.
В исходной SQL-миграции удалены только пробелы в концах строк; последовательность
SQL-токенов сохранена. Шесть сгенерированных файлов метаданных Python-пакета
не переносятся.

Корневые `src/`, `frontend/` и `tests/` сохраняют прежнюю SQLite-версию и её
незавершённые изменения для VPS. Они не заменяют действующий многопользовательский
runtime. Экспорт исходников не переключает сервер и не запускает писателей.

Для разработки платформы рабочим каталогом служит `multiuser/`. Установка
зависимостей и полный gate описаны в `multiuser/docs/testing-policy.md` и
`multiuser/docs/runtime-operations.md`. В этой версии нужны отдельная тестовая
PostgreSQL и переменная `QA_TEST_DATABASE_URL`; рабочую БД для проверок не используют.

Workflow `Quality` проверяет прежнюю версию из корня. Workflow `Multiuser Quality`
запускает собственный полный gate и Docker-репетицию из `multiuser/`, с отдельным
PostgreSQL и отдельными отчётами. `testpaths = ["tests"]` в корневом pytest
предотвращает смешивание одноимённых модулей и тестов двух приложений.
Каждая версия измеряет все свои backend/frontend-файлы и отдельно проверяет
пороги 90% строк и 90% ветвлений; результаты двух версий не усредняются.

В Git не добавляются `.env`, ключи, рабочие SQLite/PostgreSQL, пользовательские
файлы, резервные копии, сырые логи, окружения, зависимости и готовая сборка frontend.
DOCX/PDF в `tests/fixtures` являются прежними синтетическими тестовыми образцами;
они побайтно совпадают с уже отслеживаемыми образцами прежней версии.

Фактические результаты проверки платформы приведены в `layout-audit.md`.
Экспорт не является новой проверкой live OpenAI или внешнего MCP.
